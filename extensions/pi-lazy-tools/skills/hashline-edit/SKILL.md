# 锚点编辑

常规编辑沿用当前主要编辑工具。明确需要锚点编辑时，调用 `load_capability({"name":"hashline"})`，再按实际工具定义调用 `replace`、`insert` 或 `undo_last_change`。

- 先 `read` 获取新鲜锚点；参数只传三字符锚点，不传整行或代码内容。
- 替换范围只覆盖真正要改的行；插入时不重复包含保留的锚点行。
- 每个数组元素是一行，保留缩进和空行。同一文件的下一次编辑等待上一轮结果。
- 编辑后的差异提供的新锚点可以继续使用；被截断部分重新读取。
- 错误编辑立即撤销；不要在其他写入已经改变文件后声称还能安全撤销。
- 不以 Shell 写文件绕过工具的校验、并发写入队列或数据丢失保护。
