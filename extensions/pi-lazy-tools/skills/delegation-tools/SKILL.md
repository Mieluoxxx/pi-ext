# 子代理工具

没有用户授权就直接由主助手完成，不因任务复杂或工具调用多而委派。

获得授权后先确认可用目录中有 `pi-subagents` Skill，并读取它；若相关工具不可见，再调用 `load_capability({"name":"delegation"})`。若该扩展或 Skill 已卸载，明确报告委派能力不可用，不自动重装。

在下一次模型请求中依照 `subagent`、`bg_wait`、`subagent_supervisor` 的真实定义与治理规则工作。保持一个工作目录一个写入者；遵守可用性预检、工作树隔离、结果验收和原生完成通知。

启用不等于已启动任务，也不新增委派权限。治理工作流失败时不得改用 Shell/CLI 代理绕过；后台任务未结束前保留其监督和取消通道。
